# Classroom Management System Frontend

This is the admin and staff dashboard for the GPSD Class Management System. The original project design is available at [Figma](https://www.figma.com/design/sVlMnlTzbYjOQR4clZfzOA/Classroom-Management-System).

## Features
- **Student & Batch Management:** Register students, manage batches, and assign call-up numbers.
- **QR Code Attendance:** Scan student QR codes to mark daily attendance.
- **Fee Management:** Record monthly payments.
- **Material Management:** Upload PDFs and videos for specific batches.

## Running the code
1. Run `npm i` to install the dependencies.
2. Run `npm run dev` to start the development server (runs on port 5173).
